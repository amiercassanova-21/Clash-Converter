Grup. Selalu ada 🚀 Proxy berisi ♻️ Best Ping, ⚖️ Load Balance, 🔁 Fallback, 🌐 Global, dan 🛑 AdBlock. Semua trafik lewat 🚀 Proxy.

Profil aturan. Minimal = aturan ringkas (lokal .id direct, IP privat, QUIC). Lengkap = tambah rule-set geosite: iklan, privat, layanan lokal/bank/gov Indonesia, STUN, dan GEOIP ID → DIRECT. Lengkap mengunduh database geosite/geoip sekali.

Keluaran. Config penuh untuk dipakai langsung; Proxy-provider menghasilkan blok proxies saja untuk digabung ke config milik Anda.

Fingerprint TLS. Menyamarkan sidik jari TLS (uTLS) di semua node agar lebih tahan DPI. Bisa dimatikan.

AdBlock. Aturan GEOSITE ads → grup 🛑 AdBlock (REJECT/DIRECT), bisa dimatikan per situs lewat dashboard.

Blokir QUIC. QUIC = UDP 443 yang sering lolos tunnel. Mode video memakai aturan AND + sniffer; mode semua menutup seluruh UDP 443.

Lainnya. Health-check hemat baterai (lazy), WhatsApp direct di atas aturan QUIC, pisah protokol agar node cepat tak selalu menang, skip-cert untuk IP bug.
